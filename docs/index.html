The problem, in the client's own words

Tickets arrived through three uncoordinated channels — an old inbox, a Teams channel, and walk-ups. Two technicians triaged everything by gut feel, with no documented priority rules. The failure mode wasn't rare: it was structural.

Someone will write "wifi broken again" and it turns out their laptop battery died. Someone else will write three paragraphs about a printer and bury the actual urgent line — "also I can't access the ERP system" — at the bottom. — from the discovery interview

The fix couldn't just be "add AI." It had to be a system where AI does the part it's actually good at, and a human stays accountable for everything that matters.

The split that makes this work

AI recommends

  • Categorise the ticket
  • Extract the real issue from rambling or unstructured text

Code decides routing

  • High-stakes category (ERP, access) → priority queue
  • Low classifier confidence → priority queue
  • Otherwise → standard queue

Human approves

  • Sets priority
  • Assigns a technician

What actually broke, and how it was fixed

Two real bugs, found by deliberately trying to break the system — not hypothetical failure modes listed for completeness.

FOUND IN TESTING

A classification-provider outage silently deleted a ticket's future

Simulating a Gemini outage showed the exact failure this project was built to prevent — a ticket created, then invisible to every reviewer, because a failed classification wrote nothing to the database.

Fixed: classification failures now write a confidence-zero fallback, which the existing routing rule sends straight to the priority queue. No ticket can fall out of the system.

FOUND IN TESTING

Stale dashboard reads under Next.js's App Router cache

Next.js patches fetch, and the database client's REST calls went through that same patched fetch — so reads could stay cached independently of any route-level cache setting.

Fixed: a shared database client forces cache: "no-store" at the fetch level, paired with route-level and app-level cache opt-outs.
